# Bigger or Not? — clips

Short "which is bigger?" videos for the [Bigger or Not?](https://play.google.com/store/apps/details?id=com.basikcode.biggerornot) Android game.
Generated automatically by `tools/shorts_generator.py` in the (private) app repo and scheduled on
TikTok, Instagram Reels and YouTube Shorts through Metricool. Published here only so the scheduler can
fetch them by URL (GitHub Pages).

- `clips/<YYYY-MM>/*.mp4` — the month's clips
- `metricool/<YYYY-MM>.csv` and `metricool/latest.csv` — the month's schedule, ready to import
